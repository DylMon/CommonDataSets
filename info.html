About

Admissions data for top US universities, sourced directly from official Common Data Set submissions.

CommonDataSets is an independent project built to make university admissions data easier to find and compare. Instead of digging through dozens of individual PDFs scattered across university websites, we pull the numbers — acceptance rates, test score ranges, cost of attendance, demographics, and more — into one consistent, searchable place, so students and families can spend less time hunting for data and more time using it.

This site is not affiliated with, endorsed by, or sponsored by CommonDataSet.org, the Common Data Set initiative, or any of the universities whose data appears here. All figures are drawn from official, publicly published Common Data Set submissions; we neither collect nor represent university data on behalf of any institution.

CommonDataSets is an ongoing project. Coverage currently spans 33 universities, with more schools, more historical data, and new comparison tools planned as the site continues to develop.
