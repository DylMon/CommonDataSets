Chance Me

Chance Me estimates your admission odds at each school using a transparent formula built from official Common Data Set statistics — your academic profile and activities weighed exactly the way each school says it weighs them. No AI, no guesswork, and nothing you type here ever leaves your browser.

Academics

Used to estimate where you'd rank academically among each school's admitted class.

Background

Residency is determined per-school automatically — a California school only gets an in-state bump if you're from California, not just because you picked "in-state" once. Demographic data is collected for your own context only — race is not used in the formula, since it is no longer a permitted admissions factor at U.S. institutions following SFFA v. Harvard (2023). First-gen status and income are used: first-gen ties to each school's own reported "first generation" admission factor, and income has a small effect only for international applicants (see Results).

How this is calculated

Activities, Awards, and Essay are self-rated on a 1–10 scale; Letters of Recommendation on a 1–5 scale. Each scale's examples (in that section, above) are calibrated against the profiles admitted to the selective schools we track, not a generic curve. Leaving a category unrated never counts against you — it's treated as neutral, not weak.

Each school gets an Academic Index (GPA percentile within that school's own reported GPA distribution, SAT/ACT composite percentile against its 25th–75th range, and course rigor from your AP/IB/DE load, average score, and weighted-GPA strength, minus a small penalty for failed courses) and a Holistic Index (your Activities, Awards, Essay, and Letters-of-Recommendation ratings). If a school doesn't report a GPA distribution or test-score range at all, we fall back to a rough generic estimate rather than dropping that factor entirely — noted per-school below when it happens.

The two are blended using weights derived from that school's own Common Data Set "Admission Factors" table — a school that marks test scores "Very Important" and essays "Considered" leans more on your Academic Index; a school that rates both "Very Important" blends them evenly.

That blended score is compared against a base acceptance rate using a logistic model to produce a probability, then mapped to one of seven tiers. The base rate uses that school's own reported Early Action/Early Decision or Regular Decision rate when available (about a third of tracked schools report this split); otherwise it falls back to the school's overall rate adjusted by a disclosed, generic industry-wide early-round boost. If you flagged a competitive major, that rate is further reduced by a disclosed generic multiplier — we don't have real per-major CDS data, so this isn't school-specific. We also apply a small upward calibration shift throughout: a Common Data Set distribution describes the admitted class, not the full applicant pool (which includes many unrealistic "reach" applications that drag the raw acceptance rate down) — so a profile that matches the admitted-class median is treated as better odds than the bare acceptance rate would suggest.

Small additive adjustments apply for: in-state residency at public schools (scaled by how much that school says it considers residency — different for every target school, so a CA school and an NY school are judged independently), legacy status (scaled by that school's "alumni relation" importance), first-generation status (scaled by that school's "first generation" importance), and international applicants at need-aware schools.

  • This is a statistical estimate, not a prediction — admissions decisions involve factors this form can't capture.
  • Race/ethnicity is not used in scoring.
  • The competitive-major adjustment is a general heuristic, not school-specific CDS data.
  • Schools with incomplete Common Data Set submissions fall back to a generic 55/45 academic/holistic weighting, noted per-school below.
